ZUI ships the **markup and styling** — accessible, themeable components with no
behaviour baked in. That makes it a natural fit for **headless or themeable libraries** that
own state and logic and let you set the look.

These guides show how to wire ZUI's components up to popular libraries.
The pattern is always the same: the library manages state, ZUI renders it.
