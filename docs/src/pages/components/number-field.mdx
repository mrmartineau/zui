The number field puts a minus button and a plus button on each side of a number input. The three parts touch. The input has square corners. Only the outer edges of the buttons are rounded.

The buttons use the input's `step`, `min` and `max`. The arrow keys also work in the input. The buttons are not in the tab order, because the arrow keys do the same thing.

## Usage

    <input class="zui-input zui-number-field-input" type="number" id="quantity" value="1" min="0" />

    </button>

<script>
  // The buttons need this script in plain HTML. The framework components include it.
  document.addEventListener('click', (event) => {
    const button = event.target.closest('[data-zui-number-field-step]')
    const input = button?.closest('.zui-number-field')?.querySelector('input')
    if (!input || input.disabled || input.readOnly) return
    const before = input.value
    button.dataset.zuiNumberFieldStep === 'down' ? input.stepDown() : input.stepUp()
    if (input.value === before) return
    input.dispatchEvent(new Event('input', { bubbles: true }))
    input.dispatchEvent(new Event('change', { bubbles: true }))
  })
</script>`}

## Props

The `class` prop goes on the wrapper. All other props go on the `<input>`.

| Prop | Default | Description |
|---|---|---|
| `shape` | `default` | Outer corners: `default`, `hard` or `soft` |
| `decrementLabel` | `"Decrease"` | Accessible name of the minus button |
| `incrementLabel` | `"Increase"` | Accessible name of the plus button |

## CSS custom properties

Set these on `:root`, on a wrapper, or on the element. See [Component custom properties](/guides/theming#component-custom-properties). The input also uses the [Input](/components/input#css-custom-properties) properties.

| Property | Default | Description |
|---|---|---|
| `--zui-number-field-radius` | `var(--zui-input-radius, var(--radius-lg))` | Radius of the outer corners |
| `--zui-number-field-input-width` | `6rem` | Width of the input |
| `--zui-number-field-button-bg` | `var(--color-surface)` | Background colour of the buttons |
