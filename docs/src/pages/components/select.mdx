## Shape

Use the `shape` prop to change the corners. It works the same as on [Button](/components/button#shape): `default` (rounded), `hard` (square), `soft` (pill) and `squircle`.

A squircle is a rounded square with smooth corners. Browsers without `corner-shape` support show normal rounded corners. To make squircle the default everywhere, see [Squircle](/utilities/squircle).

## CSS custom properties

| Property | Default | Description |
|---|---|---|
| `--zui-select-radius` | `var(--radius-lg)` | Border radius |
| `--zui-select-border` | `var(--color-border)` | Border colour |
| `--zui-select-bg` | `var(--color-background)` | Background colour |
| `--zui-select-fg` | `var(--color-text)` | Text colour |
| `--zui-select-padding-block` | `var(--space-3xs)` | Vertical padding |
| `--zui-select-padding-inline` | `var(--space-xs)` | Horizontal padding |
