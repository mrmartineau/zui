A skeleton stands in for content while it loads. By default it **fills its container**: the full width, and the full height when the parent has a set height. When the parent has no set height, it is one line tall. Set a size when you want something else.

## Fill the container

With no size set, a skeleton takes the width and height of its parent. Give the parent a height, and the skeleton fills it. This suits an image slot or a card that must not change size when the real content arrives.

## Set a size

Use `width`, `height` or `size` (both at once). A number is pixels. A string is any CSS length. In plain HTML, set `--zui-skeleton-width`, `--zui-skeleton-height` or `--zui-skeleton-size`.

## Accessibility

A skeleton is decoration. The wrappers add `aria-hidden="true"`, so screen readers skip it. In plain HTML, add it yourself.

Tell assistive tech about the loading state on the region that holds the skeletons:

- Set `aria-busy="true"` on the region. Remove it when the content arrives.
- Add a visually hidden message with `role="status"`, such as "Loading comments". A screen reader announces it.

```html
<section aria-busy="true">
  <p class="sr-only" role="status">Loading comments</p>
  <div class="zui-skeleton" aria-hidden="true"></div>
  <div class="zui-skeleton" aria-hidden="true"></div>
</section>
```

In forced-colours mode (Windows High Contrast) each skeleton gets an outline, so it stays visible.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `width` | `string \| number` | fills the container | Width. A number is pixels |
| `height` | `string \| number` | fills the container, at least one line | Height. A number is pixels |
| `size` | `string \| number` | — | Sets width and height together |
| `aspectRatio` | `string \| number` | — | For example `16 / 9` or `1`. Height follows the width |
| `shape` | `default \| hard \| circle \| squircle` | `default` | Corner shape |
| `animation` | `pulse \| wave \| none` | `pulse` | Loading animation |

## CSS custom properties

Set these on `:root`, on a wrapper, or on the element. See [Component custom properties](/guides/theming#component-custom-properties).

| Property | Default | Description |
|---|---|---|
| `--zui-skeleton-width` | `100%` | Width |
| `--zui-skeleton-height` | `100%` | Height. When the parent has no set height, the skeleton is one line tall |
| `--zui-skeleton-size` | — | Width and height together. `width` and `height` win over it |
| `--zui-skeleton-aspect-ratio` | `auto` | Aspect ratio. Set `--zui-skeleton-height: auto` with it |
| `--zui-skeleton-radius` | `var(--radius-md)` | Border radius |
| `--zui-skeleton-bg` | `oklch(from var(--color-text) l c h / 10%)` | Base colour |
| `--zui-skeleton-highlight` | `oklch(from var(--color-text) l c h / 18%)` | Sweep colour for the `wave` animation |
