A dropzone lets people add files by dragging them onto a box, or by clicking it. It is a real `<input type="file">` stretched over the box, so it works with a keyboard, a screen reader and a form, and the browser handles the drop.

The dropzone adds three things the browser does not:

- The box highlights while files are dragged over it.
- A drop skips the input's `accept` attribute, so the dropzone checks **type** and **size** itself. Files that fail are removed from the input and named in a status line.
- A status line says what was chosen. It is a live region, so screen readers hear it.

The dropzone only picks files. You still read them from the input (`input.files`, or a `change` event) and upload them yourself.

## Plain HTML

The class names alone give you the look, the click and the drop. The highlight, the type and size check and the status line need a script. The framework wrappers load it for you. In plain HTML, import it once, with a bundler such as Vite:

```js
import { initDropzones } from '@mrmartineau/zui/dropzone'

initDropzones()
```

It uses one set of listeners on the document, so it covers every dropzone on the page, including ones added later. Set the size limit in bytes with `data-max-size` on the element that has `data-zui-dropzone`. Set the types with `accept` on the input.

## Checking files yourself

`checkFiles` is the same check the dropzone runs. Use it to check files that arrive another way, such as a paste. A server must still check every upload: the browser check is a convenience, not a guard.

```ts
import { checkFiles, formatBytes } from '@mrmartineau/zui/react'

const { accepted, rejected } = checkFiles(Array.from(files), {
  accept: 'image/*,.pdf',
  maxSize: 5 * 1024 * 1024,
})
for (const { file, reason } of rejected) {
  console.log(`${file.name}: ${reason === 'size' ? 'too big' : 'wrong type'}`)
}
```

## Accessibility

- The input is the control. It stays focusable, and a focus ring shows on the box.
- The label and hint are inside the `<label>`, so the input's name is "Drop files here, or click to browse. Images or PDF, up to 5 MB each".
- The status line has `role="status"`. It says "report.pdf (240 KB)" after a choice, and names any file that was refused.
- A drag-and-drop box is an extra. Clicking or pressing Enter or Space on the focused input opens the picker for people who cannot drag.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `label` | `string` | `Drop files here, or click to browse` | Main text |
| `hint` | `string` | — | Smaller text under the label, such as the allowed types and size |
| `maxSize` | `number` | — | Largest file in bytes. Bigger files are refused |
| `accept` | `string` | — | Allowed types: `.pdf`, `image/*`, `image/png`. Checked on drop too |
| `multiple` | `boolean` | `false` | Allow more than one file |
| `shape` | `default \| hard \| squircle` | `default` | Corner shape |
| `class` | `string` | — | Class for the wrapper. Other props go to the `<input>` |

## CSS custom properties

Set these on `:root`, on a wrapper, or on the element. See [Component custom properties](/guides/theming#component-custom-properties).

| Property | Default | Description |
|---|---|---|
| `--zui-dropzone-radius` | `var(--radius-lg)` | Border radius of the box |
| `--zui-dropzone-border` | `var(--color-border)` | Dashed border colour |
| `--zui-dropzone-accent` | `var(--color-theme)` | Border colour on hover and while dragging |
| `--zui-dropzone-bg` | `transparent` | Background colour |
| `--zui-dropzone-padding` | `var(--space-md)` | Space inside the box |
| `--zui-dropzone-icon-size` | `var(--step-3)` | Icon size |
| `--zui-dropzone-title-font-size` | `var(--step-0)` | Label size |
| `--zui-dropzone-hint-font-size` | `var(--step--1)` | Hint and status size |
