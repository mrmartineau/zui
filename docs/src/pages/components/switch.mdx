A switch is a [checkbox](/components/checkbox) drawn as a toggle. It is still a native `<input type="checkbox">`, so form submission, `:checked`, `:disabled` and keyboard use (Space) all work. The component adds `role="switch"`, so a screen reader says "on" or "off" instead of "checked".

Use a switch for a setting that takes effect straight away, such as "Notifications". Use a [checkbox](/components/checkbox) when the user must submit a form to apply the choice.

## Usage

<Demo
  html={`<label class="zui-switch">
  <input type="checkbox" role="switch" checked />
  Notifications
</label>`}
  react={`import { Switch } from '@mrmartineau/zui/react'

<Switch defaultChecked>Notifications</Switch>`}
  astro={`---
import { Switch } from '@mrmartineau/zui/astro'
---

<Switch checked>Notifications</Switch>`}
  solid={`import { Switch } from '@mrmartineau/zui/solid'

<Switch checked>Notifications</Switch>`}
  vue={`<template>
  <Switch v-model="enabled">Notifications</Switch>
</template>

<script setup>
import { ref } from 'vue'
import { Switch } from '@mrmartineau/zui/vue'

const enabled = ref(true)
</script>`}
  svelte={`<script lang="ts">
  import { Switch } from '@mrmartineau/zui/svelte'
  let enabled = $state(true)
</script>

<Switch bind:checked={enabled}>Notifications</Switch>`}
>
  <label class="zui-switch">
    <input type="checkbox" role="switch" checked />
    Notifications
  </label>
</Demo>

## Accessibility

- It is a native checkbox, so Space toggles it and it joins form submission.
- `role="switch"` makes screen readers announce on/off. The wrappers add it for you. In plain HTML, add it yourself.
- Write the label as the setting, not the action: "Notifications", not "Turn on notifications". The state is announced separately.
- In forced-colours mode (Windows High Contrast) the track and thumb switch to system colours.

## CSS custom properties

Set these on `:root`, on a wrapper, or on the element. See [Component custom properties](/guides/theming#component-custom-properties).

| Property | Default | Description |
|---|---|---|
| `--zui-switch-size` | `1.5em` | Track height. Track width is 1.8 times this |
| `--zui-switch-radius` | `var(--radius-full)` | Border radius of the track and thumb |
| `--zui-switch-accent` | `var(--color-accent)` | Track colour when on |
| `--zui-switch-track` | `oklch(from var(--color-text) l c h / 25%)` | Track colour when off |
| `--zui-switch-thumb` | `var(--color-background)` | Thumb colour |
